# The Backbone Ops & Design Inc. website

Static website for thebackbone.ca. No build step: upload these files as they are.

- `index.html` home page, plus `workshops.html`, `free-tools.html` and four industry landing pages
- `images/` photos, logos, team photos and Instagram posts
- `runtime.js` small script that renders each page and runs the menu, carousel, team switcher and animations

To publish with GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).

Still to connect: the newsletter form (Mailchimp, Kit, etc.) and the intro call booking link (Calendly or Acuity).
